# Paleta de colores

| Nombre        | Hex       | Uso                  |
| ------------- | --------- | -------------------- |
| Azul principal | `#0077FF` | Color de acento / marca |
| Azul oscuro    | `#0044AA` | Azul secundario / hover |
| Blanco         | `#FFFFFF` | Fondos claros / texto |
| Gris claro     | `#E5E5E5` | Bordes / fondos suaves |
| Gris oscuro    | `#1A1A1A` | Fondos oscuros / texto |
| Negro          | `#0D0D0D` | Fondo principal oscuro |
